# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue.** Report privately via the
[AMD Product Security portal](https://www.amd.com/en/resources/product-security.html).

Please include: description and impact, steps to reproduce, and affected versions or commits.

We aim to acknowledge reports within 1 business day.

## Scope

This policy covers code and configuration in this repository, including code inherited unchanged from [flashinfer-ai/flashinfer](https://github.com/flashinfer-ai/flashinfer), and issues in the [AITER](https://github.com/ROCm/aiter) backend found through it; AMD coordinates with those projects. For other third-party dependencies, report upstream.
